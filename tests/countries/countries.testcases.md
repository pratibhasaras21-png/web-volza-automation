# Countries Tab — Test Cases

Sourced from the QA backlog CSV (`Daily Testing and app test cases(Module wise TestCases).csv`, "Module 12 : Countries tab"). Automated by `tests/countries/countries.spec.js`. The CSV documents this module as one continuous 15-step scenario; the source spec (`Countries.specs.js`) grouped the six "Sort by" dropdown variants (steps 4-9) into a single test, which this migration expands into six individual tests/rows (`TC-COUNTRY-004`–`TC-COUNTRY-009`) so each sort variant is independently traceable — everything else maps 1:1 with the CSV step numbers.

Common precondition: user has a registered email already registered on app.volza.com, with an active paid plan (Startup, SME, or Corporate).
